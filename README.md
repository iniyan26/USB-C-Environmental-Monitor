USB-C Environmental Monitor

A custom environmental monitoring PCB designed in KiCad, intended to measure temperature, humidity, and air quality using onboard sensors.

Features
- USB-C power input
- Environmental sensor interfaces
- Power regulation and decoupling
- Custom PCB layout

Tools
- KiCad

Repository Structure
- `schematic/` — Circuit schematic
- `pcb/` — PCB layout
- `images/` — Design screenshots
